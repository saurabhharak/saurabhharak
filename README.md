## 🚀 Where I'm Heading — AI That Improves Itself

> Every system I build now answers one question: **does it get better from running?**

The frontier of GenAI isn't bigger context windows or smarter prompts. It's agents that learn from their own experience. I spent five years building the pieces: retrieval, agents, evaluation. Now I'm assembling them into a loop.

**`run → trace → judge → learn → fine-tune → run again, better`**

### Closing the self-improvement loop
- I am building agent systems that treat their own execution traces as training data: every failure becomes signal, every success becomes a reusable skill
- I am using **LLM-as-Judge evaluation as the engine of self-improvement** — in a self-improving system, the evaluator decides how far the system can grow
- I am designing persistent memory (episodic, semantic, procedural) so agents accumulate competence instead of resetting with every session

### Baking skills into weights
- I am fine-tuning open-weight models (Qwen, Llama) with **LoRA/PEFT and RL post-training**, turning agent experience into permanent model capability instead of fragile prompt libraries
- I am moving from *prompting a general model* to *shaping a specialist*, using self-generated training data from real agent runs

### Owning the inference layer
- I am self-hosting open-weight models with **vLLM and Ollama** so the improvement loop can iterate thousands of times without frontier-model economics
- I am treating model routing as architecture: frontier models for reasoning, my own served models for execution

### Speaking fluent agent — protocols & interoperability
- I am building on the **Model Context Protocol (MCP)** and agent-to-agent (A2A) standards — the HTTP of the agent internet — so my agents plug into any tool and collaborate with any other agent
- I am composing agents from standardized parts instead of hand-writing bespoke integrations, the same shift microservices brought to backend engineering a decade ago

### Guarding the agents — security & governance
- I am securing autonomous agents against **prompt injection, tool abuse, and data exfiltration** — the new attack surface that comes with agent autonomy (OWASP now lists Agentic AI Abuse in its top 10)
- I am designing **bounded-autonomy architectures** with clear escalation paths and audit trails, so enterprises can trust agents with real work
- I am turning my evaluation background into agent observability — you can't govern what you can't measure

### Building in the open
- I am documenting the whole journey — the failed loops, the eval breakdowns, the wins — in my repos and on Medium
- I am connecting with teams and builders working on self-improving agents, agent protocols, agent security, and open-weight fine-tuning
